# ABAP Learning and Build History

ABAP was developed through a documented learning journey. The detailed Python
lessons and daily development summaries are intentionally maintained separately
from this product repository so visitors can focus on the application,
architecture, security boundaries, verification, and portfolio case study.

## What moved

- 9 foundational Python lesson files
- 159 daily build summaries covering project setup, the Employee Management
  System, the web application, deployment work, workflow automation, and local
  AI-provider exploration

## Relationship to this repository

The main repository retains the engineering documents needed to understand and
run ABAP: architecture and domain design, security and provider contracts,
deployment guidance, visual specification, roadmap, the application source,
tests, and safe examples.

The learning-history repository link will be added here once it is published.
Until then, the detailed material has been preserved in a separately staged
export rather than discarded.
